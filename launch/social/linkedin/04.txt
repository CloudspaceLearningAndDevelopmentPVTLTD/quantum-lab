Your coding agent can run a quantum circuit without you.

Qubit16 speaks the Model Context Protocol, so Claude Code, Claude Desktop, Cursor or anything else that speaks MCP gets seventeen tools over one endpoint — the same engines and the same gates the web app uses.

Eleven core tools: run a circuit, halt mid-circuit and read the statevector back (no hardware will ever do that for you), list and grade challenges, generate new ones, read the free course, build a study plan, export a runnable notebook, and
— with a bearer token — submit to real hardware. One more runs the generate → verify → repair loop against a spec. Five more let an agent open an experiment record, run its steps, and write its own conclusion, which /workbench/experiments then renders for you to audit.

The transport is the part I am quietest about and happiest with: stateless JSON over a single POST, no SDK dependency, about 150 lines. GET returns 405, which the spec defines as "no server-initiated stream offered". The registry is shaped so it can be re-hosted on the official server the day it needs OAuth or resumable streams.

Then ask your agent for a Bell state and watch it check its own answer.
